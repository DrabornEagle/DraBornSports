# Google Play Politika Kontrolü — DraBornSports v0.2

## Uygulama içinde tamamlananlar

- [x] 18+ yaş bilgilendirmesi
- [x] Kesin sonuç ve kazanç garantisi verilmediğine dair açık metin
- [x] Bahis oynatma, para yatırma ve para çekme işlevi yok
- [x] Bahis sitesine yönlendirme veya “Şimdi bahis yap” çağrısı yok
- [x] Oranların demo olduğuna dair etiket
- [x] Teorik tutar ve teorik getiri dili
- [x] Sorumlu davranış uyarıları
- [x] Uygulama ücretsiz yapılandırıldı
- [x] Google Play Billing eklenmedi
- [x] Expo SDK 57 ile Android target/compile API 36 tabanı

## Play Console’da yayın öncesi yapılacaklar

- [ ] IARC içerik derecelendirme anketini doğru yanıtla
- [ ] Hedef kitleyi 18+ olarak sınırla
- [ ] Gizlilik politikası için herkese açık URL ekle
- [ ] Veri güvenliği formunu gerçek veri kullanımına göre doldur
- [ ] Finansal özellikler beyanını incele
- [ ] Kumar uygulaması/yardımcı işlev sınıflandırmasını hukuk uzmanıyla doğrula
- [ ] Gerekirse geçerli lisans, coğrafi engelleme ve Google Gambling Application başvurusu
- [ ] Store açıklamasında “garanti”, “kesin kupon”, “kesin kazanç” gibi ifadeleri kullanma
- [ ] Gerçek oran veya bahis reklamı eklenirse politikayı yeniden değerlendir
- [ ] Supabase ve harici API’ler eklendiğinde hesap silme ve veri silme URL’si ekle

## Yüksek riskli alan

Uygulama doğrudan bahis oynatmasa bile oran/performance takibi ve kupon analizi “gambling support or companion functionality” olarak yorumlanabilir. Bu nedenle yalnızca uygulama içi metin eklemek yayın onayını garanti etmez.
